# Hi, I'm Krystian 👋

IT technician, Apple enthusiast, and a fan of vintage Macs.

I believe in open source, openness, and technical integrity.
I'm not a fan of turning every useful tool into a subscription,
especially when its core features should be accessible to everyone.

## What I'm building

[macUSB](https://github.com/Kruszoneq/macUSB) makes creating bootable
macOS, Windows, and Linux USB installers easier on Mac.

My goal is to make servicing both modern and older computers simpler,
with a quick and convenient way to create installation media
directly on modern Macs.

I believe tools like this should remain free and open source,
without locking features behind a paywall.
